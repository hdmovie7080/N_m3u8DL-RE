feat: Add SONY YAY! SonyLIV Recording Telegram Bot

Implement complete Telegram bot for recording SONY YAY! streams with dual
recording methods and flexible delivery options.

FEATURES:
- Add /record HH:MM:SS command for stream recording
- Implement FFmpeg recording engine
- Implement N_m3u8DL-RE recording engine  
- Add Telegram direct upload support (up to 4.2GB)
- Add GoFile cloud upload integration
- Implement real-time progress tracking
- Add concurrent recording management (configurable slots)
- Implement automatic file cleanup after upload
- Add duration validation (HH:MM:SS format)
- Implement user-friendly inline button interface

MODULES:
- bot.py: Main Telegram bot application (540 lines)
  * Command handlers: /start, /record, /help, /about
  * Callback handlers for method/delivery selection
  * Recording orchestration and progress tracking
  * File upload management

- recording.py: Recording engines (245 lines)
  * RecorderBase abstract class
  * FFmpegRecorder implementation
  * N_m3u8DLRecorder implementation
  * RecorderFactory for instantiation
  * Progress tracking and cancellation support

- file_handler.py: File operations (198 lines)
  * FileHandler for local file management
  * GoFile API integration
  * Concurrent recording slot management
  * File size validation and cleanup

CONFIGURATION:
- .env: Complete environment configuration
- .env.example: Configuration template with documentation
- requirements.txt: Python dependencies
- Dockerfile: Container with FFmpeg and N_m3u8DL-RE
- docker-compose.yml: Container orchestration
